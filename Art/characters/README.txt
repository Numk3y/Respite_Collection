Drop friend pictures here, named after the character's id: gobby.png, justbyluck.png, spijette.png ...
PNG, JPG or WebP all work, and letter case doesn't matter (Spijette.png is fine).
If a file has a different name (e.g. goblox.png for Gobby), set Portrait Path on that character in the Inspector.
A portrait-shaped image (about 3:4, e.g. 600x800) fits the cards best; it is cropped to fill.
Until a file exists, the game shows a placeholder card with the name and class.
