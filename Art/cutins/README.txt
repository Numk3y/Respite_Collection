Ultimate cut-in pictures, named after the character's id: gobby.png, justbyluck.png, retinazer.png ...
PNG, JPG or WebP all work, and letter case doesn't matter.
If a file has a different name, set Cutin Path on that character in the Inspector.
The cut-in box is portrait-shaped (3:4, e.g. 600x800); other shapes are cropped to fill it.
A character with no cut-in picture uses their normal portrait from Art/characters/.
